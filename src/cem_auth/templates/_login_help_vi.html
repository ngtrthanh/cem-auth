📖 Hướng dẫn đăng nhập (Tiếng Việt)

Lần đầu: tạo tài khoản

{{ 'Cảng' if s else 'Admin' }} gửi bạn một link tạo tài khoản. Link chỉ dùng được 1 lần, trong {{ '72' if s else '24' }} giờ. Không chuyển link cho người khác.

  1. Cài app xác thực trên điện thoại:
    • iPhone: dùng sẵn app Mật khẩu (Passwords), không cần cài thêm.
    • Android: cài Google Authenticator hoặc Microsoft Authenticator.
  2. Mở link. Đặt mật khẩu từ 12 ký tự trở lên, gõ lại lần 2 cho khớp.
  3. Thêm tài khoản vào app xác thực:
    • Mở link trên điện thoại: chạm vào mã QR.
    • Mở link trên máy tính: dùng app xác thực trên điện thoại quét mã QR.
    App sẽ có mục {{ cfg.issuer }}, hiện 6 số đổi mỗi 30 giây.
  4. Nhập 6 số đó, bấm {{ 'Finish set-up' if s else 'Finish' }}.
{{ step('su_setup' if s else 'st_enrol', 'Trang tạo tài khoản') }}

Hằng ngày: đăng nhập

  1. Mở {{ cfg.public_url }}.
  2. Nhập {{ 'email' if s else 'tên đăng nhập' }} và mật khẩu, bấm Next.
{{ step('su_login' if s else 'st_login', 'Bước 1: email/tên đăng nhập và mật khẩu') }}
  1. Mở app xác thực, xem 6 số của mục {{ cfg.issuer }}, nhập vào và bấm Sign in.
    iPhone dùng app Mật khẩu: Safari tự gợi ý mã ngay trên bàn phím.
{{ step('su_code' if s else 'st_code', 'Bước 2: mã 6 số') }}

Nhanh hơn: đăng nhập bằng Face ID / vân tay (passkey)

  1. Đăng nhập xong lần đầu, app mở trang {{ 'Passkeys' if s else 'Your account' }}. Bấm Add a passkey on this device, rồi xác nhận bằng Face ID hoặc vân tay.
  2. Từ lần sau: bấm Sign in with a passkey, rồi Face ID hoặc vân tay. Không cần gõ gì.

Mỗi điện thoại hoặc máy tính thêm passkey một lần. iPhone, iPad và Mac dùng chung Apple ID thì dùng chung passkey. Mật khẩu và mã 6 số vẫn dùng được như cũ.

{{ step('su_account' if s else 'st_account', 'Thêm passkey') }}

Gặp lỗi

  • Báo sai: kiểm tra lại {{ 'email' if s else 'tên đăng nhập' }} và mật khẩu, rồi dùng mã mới (mỗi mã chỉ dùng được 1 lần). {% if s %}Sai 5 lần thì tài khoản bị khoá 15 phút.{% else %}Sai nhiều lần phải đợi từ 1 đến 15 phút rồi thử lại.{% endif %}
  • Mã luôn bị báo sai: giờ trên điện thoại bị lệch. Bật chế độ đặt giờ tự động.
  • Mất điện thoại, đổi điện thoại hoặc quên mật khẩu: báo {{ 'cảng' if s else 'Admin' }} để Reset. Bạn sẽ nhận link mới và làm lại phần "Lần đầu".
  • Không ai được hỏi mật khẩu hay mã 6 số của bạn, kể cả {{ 'cảng' if s else 'Admin hay IT' }}.
